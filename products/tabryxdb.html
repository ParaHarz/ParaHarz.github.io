TabryxDB

Encrypted, single-file database
for compact applications.

TabryxDB is a small database engine written in Rust. It stores multiple string-based tables in one encrypted .tbyx file, exposes a stable C ABI, and includes a Windows desktop manager for browsing and editing data.
