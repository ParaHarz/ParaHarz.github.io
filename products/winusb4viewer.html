WinUSB4Viewer

USB4 domain information
on one screen, one command.

WinUSB4Viewer shows everything Windows Settings reports about your USB4 domain — topology, silicon identity, USB4 version, and DisplayPort adapter counts — for every host router and each connected device router. A native Windows interface and a command line, read-only, with zero dependencies.
